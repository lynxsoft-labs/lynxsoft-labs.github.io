**itini** was an independent mobile navigation platform built for outdoor hiking and trail navigation.

#### Technical Highlights

- **Real-Time 3D Guidance:** Engineered on-device rendering for 3D terrain and trail navigation during active tracking.
- **GPS Engine:** Built dual-mode tracking for continuous location logging with low battery consumption.
- **Full Stack:** Developed both the Android native client application and the supporting web services API.
